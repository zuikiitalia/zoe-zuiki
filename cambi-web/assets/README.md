# Assets (loghi)

Metti qui i loghi usati nei PDF, con questi nomi esatti:

- `logo_zuiki.png`
- `logo_loveskin.png`

Puoi prenderli dalla cartella `assets/` della tua app desktop originale
(`ZuikiCambi_Mac_v16/assets/`) e copiarli qui.

Se un logo non c'è, il PDF viene comunque generato correttamente: semplicemente
non mostra il logo in alto (la funzione controlla `if logo.exists()`).
